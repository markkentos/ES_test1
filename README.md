# Эволюция архитектур нейросетей с LLM-мутациями

Данный проект демонстрирует гибридный эволюционный подход к поиску оптимальной архитектуры нейросети для задачи бинарной классификации. Вдохновлён концепцией **AlphaEvolve** от DeepMind, где большие языковые модели (LLM) используются для генерации осмысленных мутаций, а эволюционный алгоритм отбирает лучшие решения. Проект разработан в рамках подготовки к собеседованию на позицию **Стажёр Data Scientist (Риски)** в **ПАО Сбербанк**.

## 🎯 Цель проекта

Создать исследовательский прототип, который:

- **Генерирует** популяцию случайных архитектур нейросетей.
- **Оценивает** их на синтетическом датасете бинарной классификации.
- **Мутирует** архитектуры двумя способами: случайные изменения и LLM-генерируемые улучшения.
- **Отбирает** лучшие решения с помощью рангового отбора и элитизма.
- **Демонстрирует** ускорение эволюции за счёт осмысленных мутаций от LLM.

Проект наглядно показывает, как можно автоматизировать поиск эффективных моделей, что критично для банковских задач (кредитный скоринг, риск-менеджмент, оптимизация ресурсов).

## 🧠 Архитектура системы

```

┌─────────────────────────────────────────────────────────────┐
│                      Эволюционный цикл                      │
│                                                             │
│  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐ │
│  │  Инициализация│───▶│   Оценка     │───▶│   Отбор     │ │
│  │  популяции    │    │  (train_acc) │    │  (ранговый)  │ │
│  └──────────────┘    └──────────────┘    └──────────────┘ │
│         │                                      │            │
│         ▼                                      ▼            │
│  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐ │
│  │   Мутации    │◀───│   Элитизм    │◀───│  LLM-генерация│ │
│  │ (случайные   │    │ (сохранение  │    │  (топ-5      │ │
│  │  + LLM)      │    │  лучшей)     │    │   особей)    │ │
│  └──────────────┘    └──────────────┘    └──────────────┘ │
│         │                                      │            │
│         └──────────────────────────────────────┘            │
└─────────────────────────────────────────────────────────────┘

```

**Ключевые компоненты:**

- **Популяция** – 8 особей, каждая задаётся списком размеров слоёв и функциями активации.
- **Фитнес-функция** – точность на валидационной выборке после 10 эпох обучения (SGD, lr=0.01).
- **Отбор** – линейный ранговый отбор (лучший получает максимальный вес).
- **Мутации**:
  - *Случайные*: изменение числа нейронов, добавление/удаление слоя.
  - *LLM-мутации*: GigaChat анализирует архитектуру и предлагает изменения.
- **Элитизм** – топ-1 особь сохраняется без изменений.

## ⚙️ Как это работает

1. **Генерация синтетических данных**  
   Создаётся датасет из 1000 объектов, 10 признаков, с нелинейной зависимостью (синусы, косинусы, шум). Данные разделяются на train/val (80/20).

2. **Представление архитектуры**  
   Архитектура кодируется двумя списками:
   - `layer_sizes`: `[input_size, hidden1, hidden2, ..., output_size]`
   - `activations`: список активаций для каждого скрытого слоя (`relu`, `tanh`, `leaky_relu`, `elu`).

3. **Обучение и оценка**  
   Для каждой архитектуры создаётся модель PyTorch, обучается на train_loader и оценивается на val_loader. Возвращается точность.

4. **Эволюционный цикл (30 поколений)**  
   - Оцениваем всех особей.
   - Выбираем топ-5 для LLM-мутаций.
   - Для каждой из топ-5 отправляем запрос в GigaChat и получаем предложение по изменению.
   - Быстро проверяем предложенную архитектуру (5 эпох).
   - Если прирост точности ≥ 0.001, заменяем худшую особь.
   - Остальные особи мутируют случайно.
   - Сохраняем лучшую особь (элитизм).
   - Логируем прогресс.

## 🤖 Интеграция с GigaChat

Для каждой из топ-5 особей формируется промпт, который содержит:

- Текущую архитектуру (слои и активации).
- Точность на валидации.
- Статистику данных (размер выборки, доля положительных классов).

**Пример промпта:**
```

Ты — эксперт по нейросетевым архитектурам для бинарной классификации.
Дана архитектура:

- Вход: 10 признаков
- Скрытые слои: 10 -> 76 -> 1 (всего 1 скрытый слой)
- Активации скрытых слоёв: tanh
- Выход: 1 нейрон (сигмоида)

Текущая точность на валидации: 0.7100
Размер обучающей выборки: 800 объектов, доля положительных: 0.52
Размер валидационной выборки: 200 объектов

Задача: предложи ОДНО изменение архитектуры, которое может улучшить качество.
...

```

GigaChat возвращает JSON с новой архитектурой, активациями и пояснением.  
Все ответы кэшируются – повторные запросы для одинаковых архитектур не выполняются.

- **Python 3.8+**
- **PyTorch** (≥1.9)
- **NumPy**
- **Matplotlib**
- **GigaChat** – библиотека для работы с API GigaChat.

Установка зависимостей:
```bash
pip install torch numpy matplotlib gigachat
```

Для работы с GigaChat необходим токен доступа (для сотрудников Сбера).
Токен можно задать через переменную окружения:

```
export GIGACHAT_TOKEN="ваш_токен"
```

или прямо в ноутбуке (не рекомендуется для публичного использования).

## 🔍 Ключевые выводы

- **LLM эффективно генерирует осмысленные мутации** – её предложения учитывают структуру данных и текущую архитектуру, что приводит к более быстрой сходимости по сравнению с чисто случайными мутациями.
- **Гибридный подход (LLM + случайные мутации)** даёт баланс между качеством и разнообразием. LLM направляет поиск, а случайные мутации обеспечивают исследование новых областей пространства.
- **Кэширование** значительно ускоряет работу, так как одинаковые архитектуры повторно не отправляются в LLM.
- **Элитизм и ранговый отбор** предотвращают потерю лучших решений и способствуют устойчивому прогрессу.

## 🔗 Связь с вакансией и AlphaEvolve

Данный проект является упрощённой, но концептуально близкой реализацией идей **AlphaEvolve** от DeepMind. В вакансии Стажёра Data Scientist (Риски) в Сбере указаны задачи:

- *"разрабатывать и улучшать компоненты системы эволюции алгоритмов (генерация → проверка → отбор)"*
- *"экспериментировать с новыми архитектурами, искать способы сделать их более эффективными"*
- *"автоматизировать решение сложных DS-задач"*

Наш прототип демонстрирует:

1. **Генерацию** архитектур (случайную и через LLM).
2. **Проверку** (обучение и оценка на валидации).
3. **Отбор** (ранговый и элитизм).
4. **Автоматизацию** – весь процесс выполняется без участия человека.

В реальных банковских задачах (кредитный скоринг, прогнозирование дефолтов, оптимизация портфеля) такой подход позволяет:

- Быстро перебирать множество моделей и их гиперпараметров.
- Находить нетривиальные архитектуры, которые превосходят ручные решения.
- Адаптироваться к изменяющимся данным и бизнес-требованиям.

Использование LLM для генерации мутаций (как в AlphaEvolve) открывает возможности для поиска нестандартных решений, которые не пришли бы в голову человеку – например, комбинации слоёв, неочевидные функции активации или топологии.
